# Cabinet Studio usability run

A script for a browser-driving AI (Claude in Chrome, or ChatGPT's agent) to use Cabinet Studio the
way a cabinetmaker would and report where it gets stuck. Paste everything under "The prompt" into
the assistant with Cabinet Studio open in a tab (https://claude.ai/artifact/R7gZ2f9VoeAAY4SNccn7KD).

Rules for the run:
- Use a made-up client. Never open a real client's folder, and don't publish to the portal,
  send anything, or save to Dropbox.
- Start with **New → Blank room** so no real design is changed.
- One task at a time; the report is the point, not finishing.

---

## The prompt

You're testing Cabinet Studio, a design and quoting app for a custom cabinet shop, by using it the
way the shop owner would. Work in the tab that has it open. Use only the made-up client below.
Do not press Publish, Send, Save to Dropbox, Email or Text, and do not open any real client's
folder. If something would send or publish, stop and note it instead.

Start with **New → Blank room**. Then do these tasks in order. For each one, keep notes on:
- every place you weren't sure what to click or what a word meant,
- anything that looked wrong (sizes, prices, drawings, 3D),
- anything that took more than three tries,
- anything that broke, froze or reset.

1. **Room**: a 14' wide × 12' deep room, 8' ceiling. Put a window on the back wall and a door on
   the left wall (use the toolbar along the bottom of the design view).
2. **Kitchen run**: along the back wall, base cabinets with a sink base centered on the window and
   wall cabinets above, leaving room for a range. Make one cabinet a 3-drawer base.
3. **Island**: add an island (toolbar), 6' long, with drawers on both sides.
4. **Change how one is built**: double-click a base cabinet and give it a solid top instead of
   stretchers, and fixed shelves.
5. **Mouldings**: add crown to every wall cabinet and base moulding to the bases.
6. **Coffered ceiling**: turn it on (toolbar), 3 × 3, and add a picture moulding under the perimeter.
7. **Quote**: open the Quote tab. Change the wording of the Cabinets line to "Kitchen cabinetry"
   and set its price to a round number. Set painting to Site finished.
8. **Proposal**: in Clients, make a new client "Test Customer, 1 Test Rd, Sterling". Open
   **Preview what they'll see** (preview only; do not publish). Read it as the homeowner would.
9. **Drawings**: open Drawings. Add a wall section of the back wall and an enlarged crown detail.
   Look at the customer set and the shop set.
10. **Phone**: if you can, narrow the window to phone width and repeat steps 3 and 7.

Finish with a report:
- **Blockers**: what stopped you.
- **Confusing**: words, buttons or steps that weren't clear, and what you expected instead.
- **Looks wrong**: anything in the 3D, drawings, numbers or proposal that seemed off, with where.
- **Slow or awkward**: steps that took too many clicks.
- **Good**: what was easy.
Quote the exact on-screen text where you can, and say which task each note came from.
